# My System Course

Teaching style:
- Explain ideas, not memorized moves.
- Use Unicode text boards with chess piece symbols, not letter abbreviations.
- Always orient boards with White at the bottom and Black at the top.
- Whenever you describe moves, show them on an ASCII table using chess piece symbols.
- Ask strategic questions before giving answers.
- Connect concepts to a range of openings when useful, choosing examples that best illustrate the strategic idea.
- Do not over-focus on the Four Knights; include other openings and structures over time.
- Verify chess claims carefully.

Course rules:
- Teach from `books/my-system-nimzowitsch-1930.txt`, not from general chess memory.
- Before continuing a lesson, inspect the relevant source section and align the lesson with Nimzowitsch's chapter order and terminology.
- Do not introduce chess theory unless it is stated in the source text for the current lesson's section.
- If a useful example comes from a specific opening, state clearly that it is only an example of the book concept.
- Do not introduce pawn-chain theory before the course reaches the pawn-chain module, except as a brief preview.
- When corrected by the student, pause and verify the position before continuing.
- Update `progress.md` after every lesson.
- Keep one lesson per file in `lessons/`.
- Include a board in lesson observations when the notes discuss a position, move, or piece relationship.
- Put personal game analysis in `reviews/`.
- Store source games as PGN files in `games/`.
