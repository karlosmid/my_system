# Teaching Plan

Purpose:
Build a practical understanding of Nimzowitsch's *My System* by studying one strategic idea at a time, testing it with questions, and connecting it to real games.

Teaching method:
- Start each lesson with one strategic question.
- Explain the idea before showing moves.
- Use Unicode text boards for positions.
- Whenever moves are described, show them on an ASCII table.
- Prefer plans, pawn structures, and piece purpose over memorized variations.
- Connect concepts to the Four Knights whenever the structure or development pattern fits.
- Verify chess claims carefully before treating them as principles.
- End each lesson with a short progress update.

Lesson format:
1. Concept
   - Define the idea in plain language.
   - State why Nimzowitsch considered it important.

2. Position
   - Show one simple board position.
   - Ask what each side is trying to achieve.

3. Strategic questions
   - What is the center structure?
   - Which pieces are useful or misplaced?
   - What pawn breaks matter?
   - What should be overprotected, blockaded, exchanged, or avoided?

4. Explanation
   - Give the answer only after the questions.
   - Separate the general principle from the concrete position.

5. Four Knights connection
   - Relate the concept to typical Four Knights positions when possible.
   - Note when the concept does not naturally apply.

6. Exercise
   - Give a small task from a position or from one of my games.
   - Mark the result in the lesson file.

7. Review update
   - Update `progress.md`.
   - Add observations to the current lesson file.
   - Add unresolved ideas to `Needs review`.

Progress rules:
- A lesson is complete only after at least one exercise or example position.
- `progress.md` should show the current module, completed lessons, current lesson, strengths, needs review, and homework.
- Each lesson file should contain concepts, exercises, and observations.
- Reviews should focus on one theme at a time.
- PGN files in `games/` should stay unchanged; analysis belongs in `reviews/`.

Default review questions:
- What was the central pawn structure?
- Which side had more useful piece activity?
- What was the opponent's main plan?
- Was there a useful blockade, overprotection, or pawn break?
- Which move changed the strategic character of the position?
